## Dobot Magician Pick-and-Place (HAMK group project, in progress)

**Context:** Professional Growth course (BEMPP26), HAMK Riihimäki, autumn 2026.  
**Task:** Move six ping-pong balls with a suction gripper from a group-specified platform to a rack provided by the course.

**My contribution:** Set up the Dobot software on an Apple Silicon MacBook and am working through three control methods: teach-and-playback, Blockly and the Python API.  
**Team contribution:** Shared work within the group, including the start platform and the final presentation. The individual split is not recorded.

**Status:** In progress. No measured results yet.  
**AI use:** This project combined group work with AI-assisted material.  
**Not included:** The official course guide, its images and the assignment text.
